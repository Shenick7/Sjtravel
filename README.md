# sjtravel — SJ Tours and Travels

Website for **SJ Tours and Travels, Ambur, Tamil Nadu, India** — live at
https://www.sjtravel.in/

Holiday packages, flights, visa help and travel kits (₹499 each) for Indian
travellers. Enquiries come in through the Plan My Trip forms on the site,
which hand off to WhatsApp.

## Files

- `index.html` — the whole site (single page)
- `sitemap.xml` — sitemap for search engines
- `robots.txt` — allows all crawlers, points to the sitemap

## Deployment

Deployed to Vercel (project `sjtravel`). The live site is currently deployed
by manual file drop; connecting this repo to Vercel Git deployment is the
next step, so every push to `main` deploys automatically and rollbacks are
one click.
